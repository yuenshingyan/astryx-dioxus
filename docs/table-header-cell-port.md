# TableHeaderCell standalone checkpoint

`src/table/table_header_cell.rs` renders a native `th` with the `astryx-table-header-cell` styling target. It forwards native attributes and events, shares `TableCellScope` with TableCell, and adds no default styles or ARIA role.

Source: Meta Astryx `476a3153417dbf75c565f7df05b0784e94ddd59e`, `Table/TableHeaderCell.tsx` (`50d7054158f35ffb5633af1ca7103c929cc581f8`) and its spec (`cb2a9f35bec722dec14d42e454334adfe6e63cac`). There is no standalone catalog template. The existing native-table showcase demonstrates row and column headers. Table’s stylesheet already supplies density padding, header treatment, dividers, and visual truncation to its own cells. Per-cell density reflection and container-edge insets remain open. Keyboard-only cut-heading help needs integration with the shared Text/Tooltip presentation and a reliable Table membership signal; the current public props also do not expose typed context-menu actions.
