# Number Input: native numeric field

`src/number_input/` composes Field with a native number input. Caller-supplied error, warning, and success messages support attached or detached placement and are linked alongside the field description. An error sets `aria-invalid` without changing native constraint validation. The browser owns editing, step controls, and constraint validation. The callback reports the numeric value on native `change`, or `None` when the browser exposes an empty value. It does not replace browser form validation, or distinguish an empty field from invalid text the browser exposes as empty. Disabled fields are excluded from form data; read-only fields are included.

Pinned Meta Astryx sources at `476a3153417dbf75c565f7df05b0784e94ddd59e`: `NumberInput/NumberInput.tsx` (`7a9446d58c3eb13a12d60eaa4d1f692e138a59ca`), its spec (`839d670cac51b86244fa724bf569b56636ea7f46`), and the Quantity showcase (`3646b3cdbb3636676b623a35e270da0be53c0f05`). The local example keeps the label, width, initial value, and placeholder, but uses native stepping and adds explicit bounds instead of formatting the value as “items”.

## Keyboard modifier follow-up

The pinned FR4 permits ArrowUp and ArrowDown stepping only without modifiers. Because this port keeps `type="number"` rather than upstream’s text-backed spinbutton, editable fields cancel the native default for vertical arrows with Alt, Ctrl, Meta, or Shift. The event still bubbles. Plain arrows, composing keys, and Enter are left to the browser; the component does not calculate a step or emit a keyboard change callback. Native bounds, validation, and form submission are unchanged, and callers still own the value and change handler.

The style bundle and formatting checks passed, along with two focused Rust tests for the key guard. The NumberInput browser suite now checks that modified arrows leave the value, caller output, and submitted value unchanged; this browser regression was not run for the follow-up. This does not port the rest of FR4 (including upstream’s grid and immediate commit policy).
