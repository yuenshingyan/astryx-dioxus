# CheckboxListItem: standalone mode

`src/checkbox_list/checkbox_list_item.rs` composes ListItem with a single native CheckboxInput. The caller supplies the checked state and handles change requests. The checkbox uses the visible label and description for its accessible name and description, with an optional name override. The row adds no tab stop. Checked, enabled, writable rows use the accent-muted fill and reflect `data-selected="selected"` on the composed row. Disabled rows keep the native checkbox focusable through `aria-disabled`, omit the selected fill, and use the disabled text token for the visible label and description. Focus paint still comes from CheckboxInput; the row does not add a second ring.

The notification-preferences preview uses the real row with caller-owned selection. Collection mode, click delegation from the row, inherited checkbox size and availability, loading, and full catalog parity remain open.
