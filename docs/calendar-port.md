# Calendar: single-month Gregorian checkpoint

`src/calendar/` renders a controlled single-date selection in a Sunday-first Gregorian grid. The caller supplies the initial visible date and can set inclusive minimum and maximum dates. Month buttons change the visible month without moving focus away from the button. Within a month, one day is tabbable; arrow keys and Home/End move focus without changing selection. Enter or Space activates the focused day through its native button.
