# Date Input: native picker checkpoint

`src/date_input/` pairs Field with a native date input. Caller-owned status messages can appear attached or detached and are linked alongside the field description. Error feedback sets `aria-invalid` without changing native constraint validation. It accepts Gregorian `YYYY-MM-DD` values and bounds, rejects impossible dates and reversed bounds, and reports an empty value as `None`. The browser owns editing, picker presentation, and form constraint validation.

Pinned Meta Astryx sources at `476a3153417dbf75c565f7df05b0784e94ddd59e`: `DateInput/DateInput.tsx` (`610a6711752257da2c2f62c996485c79b2209056`), its spec (`dc4b270853c1bbd2d79a621b1313f7b15bd43e32`), and the Start date showcase (`94d9e8f66476c0ad6c1ecbebb0854ada6282fbb1`).
