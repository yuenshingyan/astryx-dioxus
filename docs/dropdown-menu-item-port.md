# DropdownMenuItem action and destination rows

`src/dropdown_menu/dropdown_menu_item.rs` composes Item for action rows. The row owns `menuitem` semantics and stays out of sequential tab order. Disabled actions do not invoke the caller callback. The destructive variant sets the label and description foreground without changing the shared focus paint.

Source: Meta Astryx `476a3153417dbf75c565f7df05b0784e94ddd59e`, `DropdownMenu/DropdownMenuItem.tsx` (`b071ec07156946795330d201ddd971afb293da8b`), its spec (`87db28318fcbff91a99129957047de91dd41600d`), and the action rows in the Storybook project menu. The inline preview is pointer-only. Destination rows use a single anchor as the menu item and resolve the nearest LinkProvider when enabled. Disabled and blocked destinations omit `href`; new-tab destinations add `noopener noreferrer`. Dropdown Menu lets Enter activate a live anchor natively.
