# Layer Provider: viewport sizing checkpoint

`src/layer/layer_provider.rs` supplies logical viewport insets without adding a DOM wrapper. An omitted inset inherits the parent declaration; an explicit declaration replaces it. An explicit empty inset clears the inherited reservation for that subtree. If no edge serializes, the provider supplies no inset style, so the consumer does not opt into inset-specific sizing. Explicit zero values still serialize. `Popover` consumes the nearest declaration and subtracts its insets from the viewport size budget. This limits the popup's dimensions; it does not reposition the popup away from an individual reserved edge.
